# 五分钟演示与可核实简历表述

## 演示前

按 README 启动本地服务，运行账号初始化，在本机编辑器打开凭据文件（不投屏、不复制到报告）。浏览器打开 127.0.0.1:8000；默认 langgraph + candidate，无 Key。清楚告知观众：全部订单为模拟数据，退款工单不是支付动作。

| 时间 | 操作与应看到的证据 |
|---|---|
| 0:00–0:45 | 匿名问“平台交易信息应保存多久”；展示关键词检索轨迹、引用 ID/章节和正式来源链接。默认不是 LLM 自由生成回答。 |
| 0:45–1:15 | 使用 operator 凭据登录；展示模拟订单池 ORD-10001、ORD-10002，说明脱敏与无真实订单接口。 |
| 1:15–2:15 | 发送“订单 ORD-10002 物流三天没有更新”和“订单 ORD-10001 申请电子发票”；展示 delivery/invoice 工单，运营点击接单，再完成物流工单，填写模拟处理结果。 |
| 2:15–3:00 | 发送“订单 ORD-10001 我要退款”；展示 pending，零自动资金动作。运营点击批准应被 403 拒绝。 |
| 3:00–3:45 | 切换 supervisor；批准 pending，展示 refund 工单；重复决定 API 为 409（可通过测试说明，页面不再显示已决定项）。 |
| 3:45–4:30 | 切换 auditor，点击“查看本会话审计”，展示真实检索、工单、approval_requested/approval_decided 与主管身份；审计员不能操作工单。 |
| 4:30–5:00 | 展示阶段 6.2 恢复测试与本次回归结果：同键重试复用、模型动作后异常部分恢复。说明网络失败重试按钮复用原提交，不要用新键假装重试；收尾陈述生产化局限。 |

不为演示调用 DeepSeek，不伪造远端输出。阶段 6.1 五场景是真实历史验收，本次 Fake smoke 是离线回归；两者不得混同。现场不用故意断网破坏流程，失败恢复用自动化测试的实际数据库断言展示。

## 可直接使用的简历表述

> 独立实现 OpsPilot 电商售后 Agent 演示项目，基于 FastAPI、LangGraph 与 SQLite 构建“正式知识引用—模拟订单查询—工单流转—人工退款审批—审计”闭环；维护 84 个可追溯知识块并完成关键词/本地 BGE+FAISS 检索对照。实现本地角色授权与请求幂等账本，覆盖并发重试、进程重启和业务落库后模型失败的恢复；默认无 Key 可演示，提供离线回归、容器配置与复现文档。

面试可补充：DeepSeek 仅完成五场景受控真实验证；默认 candidate，向量检索受控可选，live + vector_rag 不开放。不要写“生产上线”“真实退款”“企业客户使用”“高并发性能提升”或未经测量的百分比。测试数量与实际结果以 [交付报告](project-delivery.md) 为准。
